ATMOSPHERIC TRANSMISSION

The Problem

Laser communication through Earth's atmosphere faces a fundamental physical challenge: the air itself distorts the beam.

🌀

The Atmosphere Distorts Light

Temperature gradients and wind create random fluctuations in air's refractive index. A laser beam passing through this medium accumulates random phase errors - the wavefront is warped. This is described by Kolmogorov's turbulence theory, where distortion strength scales with the refractive index structure constant Cn².

〰️

Phase Errors Degrade Signal

The distorted wavefront causes beam spreading, intensity scintillation, and reduced coherence at the receiver. In satellite or drone laser links, this can increase bit error rates and drop communication throughput significantly.

🔧

Predict and Correct

We simulate the physics, measure the wavefront using a model Shack-Hartmann sensor, then train regression models to predict the phase distortion from sensor slope measurements. This is the core of adaptive optics: sense, predict, correct.

📋 What this demo actually shows (and what it doesn't)

▼

This simulation corrects several limitations present in our original report:

✓ Phase screens use FFT-based Kolmogorov spectrum (not sinusoid + noise)
✓ Intensity is computed from the phase via Fraunhofer diffraction (physically linked)
✓ Features are Shack-Hartmann slope measurements (not single-pixel intensity values)
✓ Training uses N independent turbulence realizations (not pixels from one image)
✓ RMSE is measured on a held-out test set (not the training data)
✓ FFT power spectral density confirms Kolmogorov statistics

Honest limitations of this approach:

✗ Linear and Ridge regression are inherently limited to linear mappings. The real wavefront-slope relationship has nonlinear components that require CNNs or deeper models.
✗ At 32×32 resolution, only 15 Zernike modes are fitted. A real AO system corrects 50-100+ modes.
✗ No closed-loop correction is demonstrated - this predicts the error but does not show the mirror command that would correct it.
✗ This remains a simulation. Real sensor noise, read noise, and photon statistics are approximated but not fully modeled.
BENCHMARK FINDINGS

Results

Honest findings from a simulation-based study. We report what the model actually achieves, and where it falls short. All numbers were computed on held-out test data.

Ridge Beats Linear - With a Caveat

Ridge Regression (α=10) achieved 12-15% lower test RMSE than Linear Regression across 50-realization experiments. However, the margin shrinks at higher turbulence (strong Cn² = 10⁻¹²), where neither linear model captures the nonlinear distortion well. The performance gain from Ridge comes from reduced overfitting, not from modelling the underlying physics better.

Low-Order Modes Are Well-Corrected

Tip, tilt, and defocus (Zernike modes 2, 3, 4) are consistently predicted with R² > 0.7, because these are the dominant contributions to wavefront error and have the strongest signal in slope measurements. Higher-order modes (coma, trefoil, spherical aberration) are poorly predicted by linear regression alone.

More Data Helps, But Hits a Wall

Increasing realizations from 10 to 100 reduces test RMSE consistently. Beyond 100 samples, improvement plateaus - indicating the linear model has reached its capacity limit. This motivates future work with convolutional neural networks or physics-informed learning.
